# Java Song Database Search Engine — Search Component

Public code sample from my contribution to a six-person Java course project.

## My role
Search Engine 1 — Qihang Shen

I developed the keyword-search component, including inverted indexing over song titles, albums, lyrics, and release years; tokenization and normalization; stop-word filtering; term-to-index mapping; and integration with the team's hash table and binary search tree structures.

## Included
- src/SearchEngine.java — indexing, tokenization, filtering, rebuild, and keyword lookup
- src/WordID.java — term-to-index mapping used by the search engine
